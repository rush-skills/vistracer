# Cable fixtures

`cable-geo-sample.json` is a synthetic sample in the layout of
TeleGeography's `cable-geo.json` (a GeoJSON FeatureCollection of
MultiLineString features with `id`, `name`, `color`, `feature_id`). The
cables and coordinates are made up: no TeleGeography data is stored in the
repository, because that data is licensed CC BY-NC-SA 3.0. The second line
of the first feature has a text coordinate and must be dropped; the last
feature has no id and must be skipped.
